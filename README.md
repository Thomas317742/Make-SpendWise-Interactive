# SpendWise Dashboard

SpendWise is a simple budgeting dashboard built using HTML, CSS, and JavaScript.

## Features

- Stores monthly budget and expense information using JavaScript variables.
- Uses a prompt to collect the user's monthly budget.
- Calculates the remaining balance.
- Uses reusable JavaScript functions.
- Displays budget, expenses, and remaining balance in the browser console.
- Allows users to add expenses.

## Technologies Used

- HTML
- CSS
- JavaScriptS
